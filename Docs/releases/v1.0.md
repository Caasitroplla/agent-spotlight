# Agent Spotlight v1.0

Search local Codex and Cursor chat history from a native SwiftUI panel.

## Included

- Open search with **Option + Command + Space** from any app.
- Search chat titles, projects, and available user and assistant messages.
- Prioritize recent saved activity, followed by the newest chats.
- Filter by app and include or exclude archived conversations.
- Navigate with the arrow keys and press Return to open a chat.
- Keep search available while older history imports in the background.
- Hide untitled Codex and Cursor chats from recent and matching results.

## Install

Download `Agent-Spotlight-v1.0-macOS-arm64.zip`, extract it, and move **Agent Spotlight.app** to Applications. Open the app once, then use its menu bar icon or global shortcut.

The downloadable app requires Apple Silicon and macOS 14 or later. It is ad-hoc signed and not notarized with Apple. macOS may block the download. You can also build from source with the included build script. The release includes a SHA-256 checksum file.

## Data and limitations

The app reads the source stores without changing them. It keeps a separate local search index and does not upload chat history. No chat history or local index is included in the repository or release download.

Recently active is a signal from saved state. It does not prove that a model is currently generating. Cursor cloud conversations are searchable only when their messages are cached locally. Source storage formats can change in future app versions.

## Verification

All 22 automated tests passed. Native testing covered search-field focus, text searches, app filters, keyboard selection, GUI chat names, and opening an exact Cursor conversation. Codex's URL route is confirmed from its registered handler and URL tests. Its destination window could not be inspected through native app control.
